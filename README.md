为小米 VELA 便携设备(尤指小米手环 10)打造的**肉鸽卡牌游戏框架**——且已经含完整可跑的战斗循环: 地图探索、卡组构建、随机战斗、奖励区域、成长型卡牌与怪物。

## 特性

**我们作为一个 框架拥有以下特性**
1. 方便的卡牌编写
 - 采用插件化的技能组

2. 怪物编写方便
 - 同上,采用插件化的技能组
 - 同时具有多种意图模式 列表循环 对象抽取(允许有n回合内不重复使用) 以及优先级更高的 **行动偏好**

3. buff编写方便
 - 有统一触发器,且目前已有(请输入文本)个不同的触发器可供使用

4. 预设影响奖励区等编写方便
 - 同上 依旧 插件化的 奖励区
## 运行

```bash
npm install        # 安装构建工具链
npm test           # 运行逻辑测试(408+ 断言, 32 个 smoke 文件)
npm run build      # 构建 RPK 包
npm start          # 开发模式
```

真机/模拟器运行需要 AIoT-IDE(小米快应用开发工具), 目标设备为 VELA 手表(如小米手环 10)。
