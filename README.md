# 尖塔之徒

为小米 VELA 便携设备(尤指小米手环 10)打造的**肉鸽卡牌游戏框架**——含完整可跑的战斗循环: 地图探索、卡组构建、随机战斗、奖励区域、成长型卡牌与怪物。

如果希望获得打包后的资源请查阅"米坛社区"

## 特性

目前有:

 1. AP限制
 2. 技能组(很方便编写)
 3. 商店系统
 4. buff效果(很方便编写 且是复杂逻辑主题)
 5. 一些很难绷的怪/卡牌
 6. 看了会被气笑的BOSS
 7. 杀戮尖塔化牌堆: 弃牌堆/洗牌回归/消耗卡(core_draw.js)
 8. 遗物系统(10 个遗物, 永久 buff 实现, 获取即生效)
 9. 卡牌一次性强化(upgradeCard/tplKey, 奖励 30% 概率出"+"版, BOSS 必强化)
10. 状态卡(rare:"status", 粘液类污染卡, 打出销毁存档同 UID 永久摆脱)
11. 限定卡(rare:"limited", 仅 BOSS 奖励可得)
12. 固定层脚本: 25 层老渔夫 BOSS 战 / 49 层高奖励入口 / 50 层 MC好成
13. 蕴含卡牌机制(怪物死亡时以本体为使用者打出卡牌)


## 运行

```bash
npm install        # 安装构建工具链
npm test           # 运行逻辑测试(271+ 断言, 24 个 smoke 文件)
npm run build      # 构建 RPK 包
npm start          # 开发模式
```

真机/模拟器运行需要 AIoT-IDE(小米快应用开发工具), 目标设备为 VELA 手表(如小米手环 10)。
