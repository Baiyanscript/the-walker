# 远行之徒

为小米 VELA 便携设备(尤指小米手环 10)打造的**肉鸽卡牌游戏框架**——含完整可跑的战斗循环: 地图探索、卡组构建、随机战斗、奖励区域、成长型卡牌与怪物。

## 特性

1. AP限制 + 技能组(很方便编写) + buff效果(复杂逻辑主题)
2. 杀戮尖塔化牌堆: 弃牌堆/洗牌回归/消耗卡(core_draw.js)
3. 遗物系统(23 个遗物, 永久 buff 实现, 获取即生效; 术石槽互斥替换)
4. 卡牌一次性强化(upgradeCard/tplKey, 奖励 30% 概率出"+"版, BOSS 必强化)
5. 状态卡(rare:"status", 粘液类污染卡, 打出销毁存档同 UID 永久摆脱)
6. **专属卡**(rare + limit 来源白名单): `limit:["BOSS"]`(BOSS 战) / `["老渔夫"]`(25 层) / `["七咒"]`(混沌预设) / `["富二代"]`, 支持 isStrict 严格模式与 require 看门人
7. **专属遗物**(与卡牌共用同一套 limit 匹配机制, 如铜制核心仅 BOSS 来源可见)
8. **七咒预设(混沌)**: 七咒之戒 7 诅咒 + 正面祝福, 专属卡池/地图/篝火生成器
9. **生成器框架**(generators.js): 奖励/地图区域插件化, 预设可声明覆盖, 失败自动回退 common
10. 固定层脚本: 25 层老渔夫 BOSS / 49 层高奖励入口 / 50 层 MC好成 / 75 层铜制机械人偶
11. 蕴含卡牌机制(怪物死亡时以本体为使用者打出卡牌)
12. 释放召唤(卡牌召唤专属怪物: 美国小伙/中东小伙等)
13. level 隐藏方案: 用户不感知等级, 数值公式化直接展示
14. 生态位去重: 原创内容优先, 移植素材仅保留不重复的生态位
15. 卡牌 39 张 / 怪物 20+ / 遗物 23 个 / 固定层 BOSS ×4

## 运行

```bash
npm install        # 安装构建工具链
npm test           # 运行逻辑测试(408+ 断言, 32 个 smoke 文件)
npm run build      # 构建 RPK 包
npm start          # 开发模式
```

真机/模拟器运行需要 AIoT-IDE(小米快应用开发工具), 目标设备为 VELA 手表(如小米手环 10)。
